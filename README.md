## ✨ คุณสมบัติหลัก

- 📋 **รองรับเพลย์ลิสต์ M3U** — แปลงและแสดงรายการช่องจากข้อมูล M3U ได้ทันที
- 🗂️ **แยกหมวดหมู่อัตโนมัติ** — จัดกลุ่มช่องตาม `group-title` เช่น ดิจิตอลทีวี, สารคดี, ภาพยนตร์
- 🎥 **รองรับ HLS (.m3u8)** — เล่นสตรีมสดผ่านลิงก์ URL
- 📐 **ปรับโหมดแสดงภาพ** — Stretch / Crop / Zoom / เต็มจอ
- 📱 **รองรับมือถือ** — ปรับขนาดอัตโนมัติ ตอบสนองทุกหน้าจอ
- 🖱️ **อินเทอร์เฟซที่ใช้ง่าย** — คลิกช่องเพื่อเล่น, ปุ่มควบคุมชัดเจน
- 🎨 **ธีมสีเข้ม** — สบายตา ดูทีวีได้นาน

## 🚀 เริ่มใช้งานทันที

### วิธีที่ 1: เปิดไฟล์โดยตรง
1. ดาวน์โหลดไฟล์ `index.html` ไปเก็บในเครื่อง
2. เปิดไฟล์ด้วยเบราว์เซอร์สมัยใหม่ (Chrome, Edge, Firefox ฯลฯ)
3. เลือกช่องรายการ หรือวางลิงก์ .m3u8 แล้วกด ▶ เล่น

### วิธีที่ 2: ใช้ผ่านเว็บไซต์
อัปโหลดไฟล์ไปยังโฮสต์เว็บ เช่น GitHub Pages แล้วเปิดลิงก์เว็บไซต์ได้เลยครับ

#EXTINF:-1 tvg-id="" tvg-name="ชื่อช่อง" tvg-logo="URL_รูปภาพ" group-title="หมวดหมู่",ชื่อช่อง
URL_ลิงก์วิดีโอ.m3u8
